# Party-Fun Admin Dashboard

Admin dashboard for managing the Party-Fun platform, built with Angular 21 and Angular Material.

## Tech Stack

- **Framework**: Angular 21
- **UI**: Angular Material 21
- **Charts**: Chart.js + ng2-charts
- **Tables**: DataTables + angular-datatables
- **Rich text**: angular-froala-wysiwyg
- **Notifications**: ngx-toastr
- **Linter**: ESLint + @angular-eslint
- **Package manager**: pnpm

## Setup

```bash
pnpm install
pnpm start
```

App runs on `http://localhost:4200`.

## Scripts

| Command | Description |
|---|---|
| `pnpm start` | Start dev server |
| `pnpm build` | Production build (output: `dist/`) |
| `pnpm test` | Run unit tests via Karma |
| `pnpm lint` | Lint with ESLint (0 warnings allowed) |
